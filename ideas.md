## Idea 1: Editorial Brutalism

**Design Movement:** Swiss International Typographic Style meets contemporary editorial brutalism

**Core Principles:**
- Strong typographic hierarchy with oversized display text as the primary visual element
- Asymmetric, off-grid layouts that feel intentional rather than accidental
- Monochromatic base with a single sharp accent color (deep amber #D97706)
- Generous negative space used as a structural device

**Color Philosophy:**
Off-white (#F5F4F0) background with near-black (#1A1A18) text. Amber accent for interactive elements only. The restraint creates sophistication — color is earned, not given.

**Layout Paradigm:**
Horizontal rule-based sectioning. Name in massive 120px+ display type anchored to the left. Content flows in a two-column editorial grid with deliberate column breaks.

**Signature Elements:**
- Thick horizontal rules (2px) as section dividers
- Oversized numbering ("01", "02") for project labels
- Monospace font for technical metadata (links, dates, tags)

**Interaction Philosophy:**
Hover states reveal underlines that draw from left to right. Project cards flip to show details. Cursor changes to a crosshair on interactive zones.

**Animation:**
Entrance animations: text lines slide up with staggered delay. Page transitions: horizontal wipe. No bouncy easing — strictly ease-in-out or linear.

**Typography System:**
- Display: "Playfair Display" — bold, editorial, authoritative
- Body: "DM Sans" — clean, modern, readable
- Mono: "JetBrains Mono" — for code/technical metadata

## Idea 2: Quiet Modernism (CHOSEN)

**Design Movement:** Scandinavian minimalism meets contemporary product design

**Core Principles:**
- Purposeful restraint — every element earns its place
- Warm neutral palette that feels human, not sterile
- Subtle depth through layered surfaces and soft shadows
- Typography as the primary visual hierarchy tool

**Color Philosophy:**
Warm stone background (#FAFAF8) with charcoal text (#1C1C1A). Muted sage green (#4A7C59) as the accent — grounded, professional, memorable. The warmth prevents the coldness of pure white/black.

**Layout Paradigm:**
Left-anchored asymmetric layout. Name and role pinned to the left third. Content breathes in the right two-thirds. Project cards arranged in an offset masonry-style grid.

**Signature Elements:**
- Thin vertical rule on the left edge of the hero section
- Dot-grid texture as a subtle background pattern
- Rounded-square project thumbnails with hover lift effect

**Interaction Philosophy:**
Smooth, unhurried transitions (300-400ms). Hover states are gentle — slight background tint, subtle shadow lift. Nothing jarring or flashy.

**Animation:**
Fade-up entrance animations with staggered delays. Smooth page transitions via opacity fade. Spring-based hover animations for cards.

**Typography System:**
- Display: "Fraunces" — warm, slightly quirky serif for name/headings
- Body: "Outfit" — geometric, clean, highly readable
- Accent: "Fira Code" — for tech labels and metadata

## Idea 3: Dark Technical

**Design Movement:** Terminal aesthetics meets modern dark UI design

**Core Principles:**
- Dark-first design with high contrast text
- Grid-based technical feel with subtle code aesthetics
- Electric blue/cyan accent for interactive elements
- Structured information density without feeling cluttered

**Color Philosophy:**
Deep charcoal (#0F1117) background, near-white (#E8E8E8) text. Electric cyan (#06B6D4) for accents and interactive states. Inspired by IDE color schemes — familiar to developers.

**Layout Paradigm:**
Full-width sections with centered content. Terminal-style hero with blinking cursor. Project cards in a clean 2-column grid with border highlights.

**Signature Elements:**
- Blinking cursor after the name in the hero
- Code-style syntax highlighting for skill tags
- Subtle scanline texture overlay on hero section

**Interaction Philosophy:**
Snappy, responsive interactions. Hover states feel like "activating" an element — border glows, background shifts. Keyboard-navigation friendly.

**Animation:**
Typewriter effect for the hero tagline. Glitch effect on hover for project cards. Smooth slide-in animations for page sections.

**Typography System:**
- Display: "Space Grotesk" — technical, modern, distinctive
- Body: "IBM Plex Sans" — clean, technical, readable
- Mono: "Fira Code" — for code snippets and tags
